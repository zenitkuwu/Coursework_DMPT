Устройство симулирует работу автоматических дверей. При обнаружении посетителя двери открываются, остаются открытыми некоторое время и закрываются при отсутствии новых посетителей. 
 Устройство предполагает несколько режимов работы:
1.	Автоматический: открытие по запросу датчика движения и автоматическое закрытие.
2.	Постоянно открыто: привод удерживает открытое положение. 
3.	Энергосберегающий: двери закрываются с минимальной задержкой после освобождения проёма. Минимальная и максимальная задержка выставляются настройками.
4.	Настройка: изменение скорости, времени удержания и допустимых положений. 
5.	Выключение/включение: остановка автоматики. 
 Для реализации необходимо использовать: сервопривод, который будет имитировать дверь; кнопки для имитации управления; PIR-датчик для фиксации появления людей возле дверей. Также должен быть использован таймер TIMx для формирования управляющего импульса и контроля задержки.
 Функционал, которым должно обладать устройство:
1)	При коротком однократном нажатии первой кнопки устройство переходит из автоматического режима в режим настроек. При длинном однократном нажатии происходит переход между настройками (изменение скорости, времени удержания, допустимых положений). 
2)	При коротком однократном нажатии второй кнопки происходит включение и выключение устройства. При длинном однократном нажатии второй кнопки происходит переход в другой режим (автоматический, постоянно открытый, энергосберегающий).
3)	С помощью потенциометра будет происходить изменение настроек. Для скорости будет разделение на три сегмента: медленно, средне и быстро. Для времени удержания интервал для настройки будет находиться между 1 и 6 секундами (базовая настройка 2 секунды). Для допустимого положения будем менять угол открытия на ±15°, ±30° и ±90°. Также для снятых с потенциометра значений должен быть предусмотрен фильтр.
4)	С помощью светодиодов будет реализован примитивный интерфей устройства: 3 светодиода будут отвечать за режим устройства (автоматический, постоянно открытый, энергосберегающий) и другие 3 светодиода будут отвечать за настройки (какой интервал выбран).
